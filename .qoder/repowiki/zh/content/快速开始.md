## 简介
本指南旨在帮助新开发者在10分钟内完成 HotGo 项目的部署与运行。HotGo 是一个基于 GoFrame2 + Vue3 + NaiveUI 的全栈开发框架，适用于中小型应用的快速开发。

本指南将分步说明如何准备环境、启动后端与前端服务、修改数据库配置，并访问系统页面。所有步骤均提供明确的命令行示例与预期输出，确保操作无歧义。

## 环境准备
在运行系统前，请确保以下环境已正确安装并配置：

### 1. Go 语言环境（1.19+）
```bash
go version
```
**预期输出：**
```
go version go1.19.x darwin/amd64
```
若未安装，请前往 [Go 官网](https://golang.org/dl/) 下载并安装。

### 2. Node.js 环境（16+）
```bash
node --version
```
**预期输出：**
```
v16.14.0
```
若未安装，请前往 [Node.js 官网](https://nodejs.org/) 下载并安装。

### 3. 包管理工具 pnpm
```bash
pnpm --version
```
若未安装，使用 npm 安装：
```bash
npm install -g pnpm
```

### 4. 数据库（MySQL）
确保已安装 MySQL 5.7+ 或 MariaDB，并启动服务。

**推荐使用 Docker 快速启动 MySQL：**
```bash
docker run -d --name hotgo-mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=root \
  -e MYSQL_DATABASE=hotgo \
  mysql:5.7
```

**验证数据库连接：**
```bash
mysql -h 127.0.0.1 -u root -p
```
输入密码 `root`，进入 MySQL 命令行。

## 后端启动
后端服务基于 Go 语言开发，位于 `server/` 目录。

### 方法一：使用 `go run` 启动
```bash
cd server
go run main.go
```
**预期输出：**
```
2024-08-27 19:02:49.123   INFO    cmd/cmd.go:123 [HotGo] Server Starting...
2024-08-27 19:02:49.124   INFO    cmd/http.go:45 [HTTP Server] Listening on :8000
```
服务将在 `http://localhost:8000` 启动。

### 方法二：使用 Makefile 启动
```bash
cd server
make http
```
该命令等价于 `go run main.go --args "http"`，仅启动 HTTP 服务。

## 前端启动
前端服务基于 Vue3 + Vite 开发，位于 `web/` 目录。

### 1. 安装依赖
```bash
cd web

```



```
vite v5.4.2 dev server running at:
> Local: http://localhost:3000/
> Network: use `--host` to expose
```
前端将在 `http://localhost:3000` 启动。

## 配置文件修改
系统配置文件位于 `server/hack/config.yaml`，需根据实际数据库信息修改。

### 1. 打开配置文件
```bash
code server/hack/config.yaml
```

### 2. 修改数据库连接信息
找到 `gfcli.gen.dao` 部分，修改 `link` 字段：
```yaml
gfcli:
  gen:
    dao:
      - link: "mysql:root:root@tcp(127.0.0.1:3306)/hotgo?loc=Local&parseTime=true&charset=utf8mb4"
        group: "default"
        removePrefix: "hg_"
```
确保：
- 用户名：`root`
- 密码：`root`
- 主机：`127.0.0.1`（若使用 Docker，可为 `host.docker.internal`）
- 数据库名：`hotgo`
- 字符集：`utf8mb4`

### 3. 导入数据库
使用提供的 `hotgo.sql` 文件初始化数据库：
```bash
mysql -h 127.0.0.1 -u root -p hotgo < server/storage/data/hotgo.sql
```
输入密码后，数据库将自动导入。

## 常见问题与解决方案

### 1. 端口冲突
**问题：** `listen tcp :8000: bind: address already in use`
**解决方案：**
- 查找占用端口的进程：
  ```bash
  lsof -i :8000
  ```
- 结束进程：
  ```bash
  kill -9 <PID>
  ```
- 或修改后端端口，在 `server/internal/config/config.go` 中调整监听端口。

### 2. 数据库连接失败
**问题：** `dial tcp 127.0.0.1:3306: connect: connection refused`
**解决方案：**
- 确认 MySQL 服务已启动。
- 检查 `config.yaml` 中的数据库地址、端口、用户名、密码是否正确。
- 若使用 Docker，确保容器正常运行：
  ```bash
  docker ps | grep mysql
  ```

### 3. 前端无法访问后端 API
**问题：** 前端报错 `CORS error` 或 `Network Error`
**解决方案：**
- 确认后端服务已启动且监听 `:8000`。
- 检查前端 `vite.config.ts` 中的代理配置，确保 `/api` 请求被代理到 `http://localhost:8000`。

### 4. 依赖安装失败
**问题：** `pnpm install` 报错网络问题
**解决方案：**
- 更换 npm 镜像源：
  ```bash
  npm config set registry https://registry.npmmirror.com
  ```
- 重新运行 `pnpm install`。
